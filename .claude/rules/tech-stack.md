# Technology Stack

このプロジェクトで使用する技術スタックと、その利用方針を定義します。

## Core

- Nuxt 4
- Vue 3
- TypeScript

Nuxtの標準的な構成・ベストプラクティスを優先してください。

## Styling

- CSS
- 必要に応じてCSS ModulesまたはScoped CSS
- 既存のClaude Designモックのデザインを可能な限り再現する

UIライブラリを導入する場合は、既存のデザインや世界観を損なわないかを確認してください。

MVPでは、UIライブラリを安易に導入せず、必要最小限の依存関係にしてください。

## Animation

基本的なアニメーションには **GSAP** を使用します。

GSAPは特に以下の用途で使用します。

- 複数要素を同期させるアニメーション
- タイムラインを持つアニメーション
- 儀式的な演出
- 紙の移動・変形
- 炎
- 灰
- フェード
- カメラ的な移動・ズーム
- 複数状態にまたがるアニメーション

単純なUIトランジションについては、CSS transition / animationやVue / Nuxtの機能を優先してください。

### Animation Library Policy

原則として、MVPではGSAPをアニメーションの中心とします。

Riveなどの別のアニメーションランタイムは、GSAPでは表現が困難な要件が明確になった場合にのみ導入を検討してください。

アニメーションライブラリを複数導入する場合は、それぞれの責務を明確にしてください。

## State Management

MVPでは、必要以上にグローバル状態管理ライブラリを導入しません。

まずはVueの標準的なstate managementとNuxtの機能で実装してください。

状態が複雑になり、明確なメリットがある場合のみ追加ライブラリの導入を検討してください。

## Data Persistence

MVPでは、バックエンドやデータベースを必要以上に導入しません。

まずはローカルで完結する構成を優先します。

永続化が必要になった場合は、その時点で最適な方法を検討してください。

## Dependencies

新しいnpm packageを追加する前に、

1. 本当に必要か
2. 既存のNuxt / Vue / CSS / GSAPで実現できないか
3. プロジェクト全体への依存関係を増やす価値があるか

を確認してください。

「便利そう」という理由だけで依存関係を増やさないでください。
